Why your playful life-expectancy date can change

See how completed age, the calculation day and the selected population reference affect WhenWillIDie’s entertainment-only date.

By the WhenWillIDie project · Published September 9, 2026 · Software guide

The display follows a reproducible calculation

WhenWillIDie derives completed age from the supplied birth date using the current UTC date. It selects a remaining-years value from the bundled reference table, converts that value to days and adds it to the calculation date. The calendar output follows those inputs; it is not a measurement of someone’s remaining life.

Changing the reference changes the input

The interface offers an equal average, the male table and the female table. These are alternative population references. The equal average is a calculation choice in this app, not an official combined-population estimate or a gender assignment.

The calendar itself is another input

A calculation made on another day can produce a different displayed date. Crossing a completed-age boundary can also select a different row. The implementation uses integer ages rather than interpolating a fractional age between rows.

  1. Check which population reference is selected.
  2. Remember that the calculation uses today’s UTC date.
  3. Treat the precise calendar day as the result of arithmetic.
  4. Skip the reveal if the framing is uncomfortable.

A comparison is about assumptions

The reference controls make a simple assumption visible. They do not incorporate diagnoses, behavior, treatment or future changes in population mortality. The app supplies no personal confidence interval. The published SSA table is the reference source; the project’s calculation code explains how it becomes a date.

Questions about this guide

Does a later displayed date mean my health improved?

No. This app does not assess health changes. Its output changes with the calculation inputs.

Does the average setting infer my gender?

No. It takes an equal arithmetic average of two table columns without inferring gender from a record.
